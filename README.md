# AlphaFlowX App

Standalone mobile app shell for AlphaFlowX, built with Capacitor.

## Target

- iPhone
- Android
- Huawei Android / AppGallery

This app is intentionally isolated from the current website codebase. It does not change the existing AlphaFlowX mobile web experience.

## Tech choice

- Capacitor
- Vite
- Single shared web codebase

## Local development

```bash
cd alphaflowx-app
npm install
npm run dev
```

## Build web assets

```bash
cd alphaflowx-app
npm run build
```

## Add native projects

```bash
cd alphaflowx-app
npm run cap:add:android
npm run cap:add:ios
```

## Sync native projects

```bash
cd alphaflowx-app
npm run cap:sync
```

## Open in Android Studio / Xcode

```bash
cd alphaflowx-app
npm run cap:open:android
npm run cap:open:ios
```

## Huawei release

Huawei AppGallery can use the Android project generated by Capacitor. If later needed, HMS features such as Push Kit can be added on top of the Android project without changing the iOS codebase.

## Android release

```bash
cd alphaflowx-app
cp android/keystore.properties.example android/keystore.properties
# edit android/keystore.properties
npm run android:release
```

## Current app behavior

- Native iOS / Android / Huawei Android builds open `https://www.alphaflowx.com` inside the app WebView
- The local Vite page is only used as a development fallback / shell
- The website remains unchanged; this project is a separate app wrapper
- Native share support is available in the local shell layer for later extension
